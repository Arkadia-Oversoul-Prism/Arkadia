# CP-10.6 — ORIGIN DISCRIMINATION SEMANTICS

**Status:** sharpened / boundary reached / schema-only / no mechanism selected

## Job
Determine whether technology-neutral semantics can precisely separate:
`ASSOCIATED WITH EVENT ≠ ORIGINATED EVENT`
and
`INTERACTED WITH EVENT ≠ DELIBERATELY ORIGINATED EVENT`.

## D3 minimum properties
O1 subject specificity; O2 event specificity; O3 directionality; O4 non-substitutability; O5 event-level binding; O6 temporal correspondence; O7 contextual correspondence.

These properties sharply constrain false positives but do not themselves answer the positive question: **what observable property establishes that the subject originated the event?**

## D4 minimum properties
P1 subject-originated; P2 intentionality relevance; P3 act specificity; P4 non-automaticity; P5 non-replay; P6 non-delegation; P7 temporal correspondence.

Again, the vocabulary can specify the target and its exclusions but cannot instantiate the positive observable relation.

## False-positive classes closed
Authenticated association, session ownership, ordinary interaction, automated execution, delegation, derived events, witness observation, successful execution, unrelated deliberate interaction, authentication-triggered automation, replay, ambiguous interaction.

## Boundary test
- Semantic sharpening without technology: PASS.
- Positive D3/D4 instantiation without specifying how evidence is produced: NOT ESTABLISHED.
- Circular definition as proof: rejected.

## Result
The vocabulary layer reached a genuine positive-instantiation boundary. CP-10.6 did not select a mechanism. It established that the next step must either examine an actual mechanism candidate or formally argue why a conjunction/boundary is required.
