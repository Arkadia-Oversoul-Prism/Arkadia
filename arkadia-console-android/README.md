# Arkadia Console

Native Android instrument for Arkadia Prism.

It is the human edge of Arkadia, not a second database or a mobile copy of every web screen.

- FIELD: encounter the living Solariun projection.
- FOCUS / DEEP: inspect semantic objects, source and state.
- ARKANA: interrogate intelligence in context.
- CAPTURE: record observations into the canonical WorkEvent spine.
- DECIDE: record a human proposal decision without treating it as execution.
- VERIFY: refresh canonical state and events.

The first native gate deliberately uses an explicit Oracle URL + bearer token bootstrap. There is no silent backend fallback. The next gate replaces manual token entry with native Firebase Auth and ID-token refresh.

Canonical identity, authorization, execution, persistence and evidence remain server-side.
