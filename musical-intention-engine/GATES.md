# MIE · MVP-01 Gates

| Gate | Boundary | Required evidence |
|---|---|---|
| 00 | Reconnaissance | verified build state |
| 01 | Capture | reliable Android capture/replay |
| 02 | Interpretation | type + confidence + evidence |
| 03 | Materialization | inspectable MusicalObject |
| 04 | Transformation | one meaningful reversible change |
| 05 | Change loop | repeatable compare/keep/revise |
| 06 | Continuity | ancestry back to original |
| 07 | Mobile instrument | real-device usability |
| 08 | Measurement | TTMI/TTCS/ITS/IP/RC/DWM protocol |
| 09 | Experiment run | hum/tap/speak/repeat evidence |
| 10 | Integrity review | product-hypothesis review |

A gate is not passed because code exists. It requires implementation, test, evidence, documentation, and commit.
