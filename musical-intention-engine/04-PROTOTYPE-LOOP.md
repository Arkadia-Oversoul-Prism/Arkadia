# MIE · Prototype Loop

## MVP-01 contract

CAPTURE → UNDERSTAND → MATERIALIZE → MANIPULATE → HEAR → KEEP/REVISE

The user must be able to:

1. capture a musical idea on a phone;
2. inspect it;
3. receive a basic interpretation;
4. obtain a musical object;
5. apply one meaningful transformation;
6. hear the result;
7. preserve the original;
8. compare original and transformed versions;
9. return to the original;
10. repeat.

## Deliberate exclusions

No social layer, marketplace, publishing flow, full DAW timeline, full mixer, plugin ecosystem, subscription system, generative-song feed, or elaborate onboarding.

## First transformation

Choose exactly one transformation based on experimental evidence. Candidate classes include tempo, pitch, rhythm, groove, density, or texture.

The implementation must preserve the original.
