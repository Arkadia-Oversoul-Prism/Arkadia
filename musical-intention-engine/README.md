# Musical Intention Engine (MIE)

MIE is the mobile-first instrument research track inside the Arkadia Prism architecture.

> Build the shortest possible interface between musical intention and manipulable sound.

MIE is not a smaller DAW and not an AI song generator. Its experimental loop is:

HUMAN → INTENTION → CAPTURE → INTERPRETATION → MUSICAL OBJECT → TRANSFORMATION → SOUND

## Prism relationship

MIE is a bounded product/experience substrate inside the larger Prism repository. It may reuse repository-level engineering, testing, identity, Android, and agent infrastructure, but its musical grammar remains independently discoverable.

Current Android projection substrate: `sonata-android/`.
MIE implementation/docs: `musical-intention-engine/`.

No MIE experiment may silently alter SolSpire, Engineering Lab, identity, or production control-plane semantics.
