# EXP-001 · Raw Capture

**Status:** PARTIAL  
**Date:** 2026-10-02  
**Purpose:** establish the first bridge from human musical impulse to captured sound.

## Observed

A short clip was successfully captured and replayed on a real Android phone using the initial mobile prototype. The observed interface used HOLD TO CAPTURE → playback → KEEP/CHANGE.

## Repository reconciliation

The source implementation of that observed prototype was not found in the current Prism `main` tree. The screenshot is evidence of observed behavior, not source provenance.

## Current implementation

The native Prism Android substrate now contains an MIE capture path that records 16 kHz mono PCM into a WAV source and preserves the original file.
