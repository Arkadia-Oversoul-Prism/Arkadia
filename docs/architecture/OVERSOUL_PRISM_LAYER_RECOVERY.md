## Historical edge topology

The A01 implementation description establishes:

- 12 parent branches, A01–A12.
- Each branch recurses internally from L01 through L12.
- Each layer receives the growing state produced by the preceding layer.
- Intermediate state is persisted.
- The branches are described as parallel at the parent level.

Therefore the strongest supported edge model is:

`Axx-L01 → Axx-L02 → ... → Axx-L12`

for each Axx.

**Not established:** cross-function edges such as `A01-L03 → A02-L04`, diagonal edges, feedback edges between branches, or a complete graph topology.

Those remain **UNKNOWN**.
