## Design Notes

**SQLiteJobStore**
- Per-thread connections via `threading.local()` — WAL allows concurrent readers; `BEGIN IMMEDIATE` serialises writers.
- `next_job_id(timeout)` polls with 0.5s sleep intervals, replacing `queue.Queue.get(timeout)`. Semantics identical to callers.
- `_claim_one()` issues `BEGIN IMMEDIATE → SELECT → UPDATE → COMMIT` atomically. An `OperationalError` (write-lock contention) causes immediate backoff and retry within the timeout window.
- `_recover_running_jobs()` runs in `__init__`: any `running` row is reset to `pending`. This is the crash recovery mechanism — no separate migration step needed.
- `task_done()` is a no-op preserved for API parity with `queue.Queue`.

**SQLiteGoalStore**
- `history` column stores a JSON array capped at `HISTORY_CAP` (50) entries.
- `_under_hourly_cap()` is a pure function copied verbatim from `kernel/goals.py` — no logic divergence.
- `due_goals()` filters by `status = 'active'` and `next_run <= now` in SQL, then applies the hourly cap in Python.
