## Migration Strategy

No data migration in B1.1. The JSON→SQLite import runs in B1.3 (Worker Integration), on first startup when `data/runtime.db` does not exist. JSON files (`data/job_store.json`, `data/goal_store.json`) are preserved read-only throughout B1 as the rollback path.

---

## Rollback Strategy

`kernel/storage/` can be deleted and `kernel/jobs.py` / `kernel/goals.py` remain untouched. The in-memory store continues to operate. Zero user impact. No migration has run yet.
