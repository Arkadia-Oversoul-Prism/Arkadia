## Database Schema Added

### Table: `corpus_sync_state`

| Column | Type | Constraints |
|---|---|---|
| `key` | TEXT | PRIMARY KEY — e.g. `"owner/repo:main"` |
| `tree_sha` | TEXT | NOT NULL — last successful tree SHA from GitHub |
| `synced_at` | REAL | NOT NULL — unix timestamp of last successful sync |
| `file_count` | INTEGER | NOT NULL DEFAULT 0 |

### Table: `corpus_file_state`

| Column | Type | Constraints |
|---|---|---|
| `repo_key` | TEXT | NOT NULL — FK to `corpus_sync_state.key` |
| `path` | TEXT | NOT NULL — e.g. `"docs/ARKADIA_SPEC_v3.md"` |
| `file_sha` | TEXT | NOT NULL — git blob SHA for change detection |
| `ingested_at` | REAL | NOT NULL — unix timestamp of ingestion |
| *(repo_key, path)* | — | PRIMARY KEY (composite) |

Index: `idx_corpus_file_state_repo_key` on `corpus_file_state(repo_key)`
