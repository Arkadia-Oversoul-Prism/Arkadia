# CP-MOVE6 — Weekly Synthesis

**SCHEMA_ONLY / READ_ONLY / NORMATIVE / TECHNOLOGY_NEUTRAL**

## Purpose

A bounded weekly aggregation surface over Daily Pulses and relevant WorkEvents.

> The synthesis can reveal the shape of the week. It cannot become the authority over what happens next.

## Chain

`HUMAN SOVEREIGNTY → IDENTITY → WORKSPACE → WORKLOAD → WORKEVENT → DAILY PULSE → WEEKLY SYNTHESIS → GOVERNED ACTION → K15 → K3`

Protected chain remains:

`HUMAN INTENT → APPROVAL EVENT → PROVENANCE → AUTHORIZATION → PASS SPEC → K15 → K3 → MUTATION`

## Distinctions

`SYNTHESIS ≠ AUTHORITY ≠ PROVENANCE ≠ AUTHORIZATION ≠ DECISION ≠ EXECUTION`

`PATTERN ≠ CAUSATION`
`TREND ≠ FACT`
`RECOMMENDATION ≠ APPROVAL`
`SYNTHESIS ≠ MEMORY SYSTEM`

`OBSERVED / CORROBORATED / INDICATIVE / HYPOTHESIS / UNKNOWN`

`DECISION PENDING ≠ DECISION MADE`
`RECOMMENDATION ≠ APPROVAL`
