# M03 — NovaNet Public Field

Status: PENDING
Depends on: M02

## Objective
Make NovaNet the public social field while preserving private ReasoMate and private Knowledge OS boundaries.

## Required invariants
- Public identity projections, posts, transmissions, and interactions use existing social infrastructure.
- ReasoMate conversation is private and user-scoped.
- Private memory and Knowledge OS state do not become public feed state.
- No second social or identity substrate.

## Acceptance
NovaNet renders a coherent public feed and authenticated users can distinguish public field state from their private ReasoMate state.

## Verification
Run feed, identity, authentication, privacy-boundary, and build checks.

## Stop condition
Stop at review. Do not advance until M03 is accepted.
